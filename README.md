### VeroPath — Multi-Agent ESG Compliance AI Platform

> Production-grade multi-agent AI backend for ESG compliance reporting aligned with **UAE FDL#11**. Built the AI backend end-to-end across architecture, implementation, testing, deployment, and production readiness.

<sub>**Highlights**</sub>
- FastAPI service with **CrewAI**-orchestrated agents for data analysis, compliance checking, and report generation
- **RAG** regulatory grounding with embeddings, vector retrieval, and tenant-isolated knowledge
- Versioned prompts, citation grounding, quality gates, audit logging, provider fallback, response caching, cost monitoring
- Emissions estimation, anomaly detection, sustainability advisory, and human sign-off controls
- Dockerized, deployed to **Azure Container Apps** via **Azure DevOps CI/CD**
